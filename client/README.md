# Resume Builder – Client

This is the React + Vite frontend for the Resume Builder app. For full project documentation, setup, and API details, see the repository root README:

- ../../README.md

Quick start (frontend only):
- npm install
- npm run dev

Notes:
- During development, API requests to /api are proxied by Vite. Adjust client/vite.config.js proxy target to your backend origin if needed.
- In production builds, set VITE_BASE_URL to your server origin so the client points to the correct API.
